# 참고 형식과 적용 기준

2026-10-16 운영 카탈로그의 기존 쿠팡 등록 상품 244개와 HTML을 읽고 아래 형식을 확인했다.
원본 응답과 판매 계정 정보는 이 스킬에 포함하지 않는다. 이후 작업에서는 현재
상품을 다시 조회하며 이 문서를 고정 상품 템플릿으로 사용하지 않는다.

## 참고 상품 찾기

한 페이지의 최신 상품을 임의로 고르지 않는다. 대상 원본에서 번역한 한국어 상품 종류·동의어를 준비하고, 현재 실행에 배정된 읽기 도구로 다음 도우미를 호출한다. 이 도우미는 로컬 등록 카탈로그만 한 페이지씩 읽으며 상품·가격·이미지를 변경하거나 공급자 페이지를 열지 않는다.

```json
{"projectId":"현재 작업의 프로젝트 UUID","queries":["장스탠드","조명","램프"],"categoryCode":"78359"}
```

```sh
node "$SOURCING_PROCESSING_SKILL_DIR/scripts/reference-profile.mjs" ./reference-input.json > "$PAPERCLIP_RUN_SCRATCH_DIR/reference-profile.json"
```

- `queries`는 대상의 실제 상품 종류에서 고른 한국어 검색어다. 예제의 조명 검색어나 카테고리를 다른 상품에 고정하지 않는다. 사용자가 특정 참고 상품을 지정하면 `referenceIds`(최대 3개)도 전달한다.
- 20개 단위로 끝까지 순차 조회한다. 기본 상한은 100페이지이며 `catalogComplete=false`는 전체 조회가 아니다. 중복 페이지·조회 중 변경은 오류로 보고해 누락을 숨기지 않는다.
- 상품명 일치 단어로 후보를 고르고 같은 카테고리는 보조 점수로만 사용한다. 상위 3개의 상세를 재조회해 ID·revision·형식을 남긴다. 단어 일치가 사용 목적·상품 종류의 일치를 보증하지 않으므로 최종 선택 이유를 기록한다.
- `displaySamples`의 내부 번호는 표시 샘플에서만 제거된다. 해당 참고 상품이나 SKU ID는 수정되지 않는다. 경고가 붙은 빈 옵션·중복 구간은 새 상품에서 따라 하지 않는다.
- 참고 상품에서 가져올 것은 표현·구성이다. 후보의 치수·재질·이미지·가격·인증은 대상의 사실이 아니다. 전체 카탈로그 원문은 결과 보고서에 덤프하지 않는다.

## 확인한 형식

상품명 길이는 24~38자(중앙값 28자)였고, 232개에 옵션 설명, 169개에 상세 페이지 구간이 있었다. 229개에는 SKU 표시 이름 앞 내부 번호가, 62개에는 빈 옵션 값이, 6개에는 중복 옵션 설명이 있었다. 길이는 관찰값이며 새 상품의 의무 글자 수나 품질 보증으로 사용하지 않는다. 잘못된 속성·오타·과장 표현도 원본과 대조한다.

| 영역 | 확인한 형식 | 새 상품 적용 기준 |
| --- | --- | --- |
| 상품명 | 상품 종류, 사용 장소·용도, 색상·형태를 한국어로 조합 | 대상 근거가 있는 키워드만 선택하고 반복 동의어를 줄인다. |
| 옵션명·값 | 한국어 SKU 이름과 치수/색상 등 구매 선택 정보 | 원본 SKU별 차이를 유지하며 숫자·단위를 변경하지 않는다. |
| 대표·옵션 이미지 | 대표 이미지와 SKU별 이미지 연결 | 해당 대상 상품의 이미지를 사용한다. 최신 요구는 흰 배경·상품 전체 중앙 배치이며 기존 등록 사진의 배경까지 복제하지 않는다. |
| 상세 설명 | 가운데 정렬 안내, 옵션 이미지/설명 표, 상세 이미지 순서 | 필요한 안내만 사용한다. 비교 표와 상세 설명은 실제 대상 SKU로 다시 구성한다. |
| 저장 정보 | 공통 상품 ID/revision, SKU ID, 판매가, 카테고리, 쇼핑몰별 등록 정보 | 형식 가공으로 판매가·등록 ID·등록 카테고리를 바꾸지 않는다. |

기존 사례에는 옵션 설명 구간이 두 번 반복되거나, 치수 옵션이 색상 속성으로
들어간 데이터도 있었다. 참고 형식을 복제하는 것은 이런 오류까지 복제하는
뜻이 아니다. 이미 등록한 상품의 속성 이름은 실제 제공자 제약을 먼저 확인한다.
HTML에 있지만 현재 SKU 목록에 없는 선택지를 새로 만들거나 노출하지 않는다.

권장 HTML 구성은 다음과 같다. 전 영역이 필요한 것은 아니다.

1. 대상 상품에 적용되는 안내만 짧게 표시한다.
2. 구매 옵션이 여럿이면 이미지와 원본 규격을 같은 순서로 비교한다.
3. 근거가 있는 특징·규격을 읽기 쉬운 한국어 문장 또는 표로 표시한다.
4. 실제 대상 상품의 상세 이미지를 중복 없이 배치한다.

인증·재질·국내 배송 기간·반품 조건·판매자 정보는 디자인 요소가 아니다.
참고 상품과 같아 보여도 대상에 대한 확인 자료가 없으면 가져오지 않는다.
