# 지마켓·옥션 연결 안내

도비 오더스 0.3.0 · 2026-10-14

지마켓·옥션은 ESM에서 직접 로그인한 세션으로 날짜별 주문을 수집합니다. 판매자 ID별로 연결을 만들며, 비밀번호나 쿠키를 채팅에 입력할 필요가 없습니다. 현재 서버와 실제 계정의 호환성은 아직 검증하지 않았습니다.

## 프로그램과 계정 준비

1. 프로그램 ZIP을 새 폴더에 모두 풀고 `도비 오더스.exe`를 엽니다. 문제가 있으면 `실행.cmd`에서 로그를 확인합니다. 기본 주소는 `http://127.0.0.1:4317`입니다.
2. **쇼핑몰 · 배송대행 연결**에서 ESM을 찾아 **연결 설정**을 누릅니다.
3. 계정 이름을 정하고 연결 방식 **지마켓·옥션 API · 브라우저 세션 연결**을 선택합니다.
4. **지마켓** 또는 **옥션**을 선택하고 그 쇼핑몰의 **ESM 판매자 ID**를 입력한 뒤 저장합니다. 지마켓·옥션 또는 여러 판매자 ID는 각각 별도 연결로 만듭니다.

## 도우미 설치와 페어링

1. 앱의 **브라우저 도우미**에서 도우미 ZIP을 내려받아 압축을 풉니다. 프로그램의 `browser-helper` 폴더를 사용해도 됩니다.
2. Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켭니다. **압축해제된 확장 프로그램을 로드**를 눌러 `manifest.json`이 있는 도우미 폴더를 선택합니다. Edge는 `edge://extensions`에서 같은 절차를 사용합니다.
3. 앱의 도우미 안내에서 **연결 코드 만들기**를 누르고 표시된 코드를 도우미 팝업에 입력해 연결합니다. 코드는 10분 동안 유효합니다. 앱이 재시작되면 다시 페어링합니다.

확장 파일은 제공했지만 실제 브라우저에 설치하지 않았습니다. 로그인할 브라우저 프로필과 도우미를 설치한 프로필이 같아야 합니다.

## ESM 로그인 세션 연결

1. ESM 홈페이지에서 해당 계정으로 직접 로그인합니다. 추가 인증이 나오면 사이트에서 완료합니다.
2. 앱에서 해당 계정의 **브라우저로 연결**을 누릅니다. 표시된 판매자와 쇼핑몰을 확인합니다. 연결 요청은 **5분 동안 한 번** 유효합니다.
3. 로그인한 ESM 탭에서 도우미를 열고 **ESM 세션 연결**을 선택합니다. 앱에서 요청한 계정을 고릅니다.
4. **현재 ESM 탭과 승인 확인**을 누릅니다. 표시된 계정과 사이트를 확인하고 로그인 쿠키 사용 동의를 체크합니다.
5. **지마켓·옥션 세션 연결**을 누르고 ESM 쿠키용 선택 권한을 허용합니다. 도우미는 현재 ESM 탭의 쿠키만 이 PC의 앱에 보내며, 처리 후 선택 권한을 해제합니다.
6. 앱에서 **연결 상태 확인**을 누릅니다. 판매자 ID 대조가 성공하면 **인증 확인됨**으로 표시됩니다.

저장된 설정만으로 로그인 성공을 표시하지 않습니다. 계정이 다르거나 요청이 만료되면 로그인과 설정을 확인하고 새 연결 요청을 만드세요. 앱은 세션을 Windows 현재 사용자 DPAPI로 암호화하고 쿠키값을 일반 응답·백업·로그에 포함하지 않습니다. 도우미는 쿠키를 확장 저장소에 저장하지 않습니다.

## 주문 수집과 재연결

**주문 수집**에서 연결된 계정과 시작·종료 날짜를 선택합니다. 종료일을 포함한 주문일 범위로 신규·발송대기·배송중·배송완료·구매확정 주문을 조회합니다. 구매확정은 발송일 검색 범위를 확장한 뒤 주문일로 다시 걸러냅니다.

오늘부터 365일 이내 기간을 지원하며, 한 번에 최대 10,000품목을 저장합니다. 상태별 페이지 크기는 500개, 최대 100페이지입니다. 마지막 페이지·상세 응답·필수 필드를 확인하지 못하면 이번 수집 결과 전체를 반영하지 않습니다. 기간을 줄이거나 표시된 오류를 해결한 뒤 다시 수집하세요.

같은 주문을 다시 가져오면 판매처 정보를 갱신하면서 작업 메모·보류·수동 송장을 보존합니다. 긴 주문번호는 문자열로 유지합니다. 선물·클레임·알 수 없는 상태 또는 이미 배송한 주문은 배송대행에 사용할 수량을 0으로 표시하므로 상세를 확인해주세요.

세션과 서버가 반환한 쿠키 갱신은 앱 재시작 후에도 암호화 저장소에서 사용할 수 있습니다. ESM의 만료·로그아웃 정책에 따라 다시 로그인이 필요할 수 있으며 영구 연결은 보장하지 않습니다. 만료 메시지가 나오면 브라우저에서 정상 로그인한 뒤 **세션 다시 연결**을 진행합니다. 백업 복원 또는 다른 Windows 계정·PC로 이동한 뒤에도 세션을 다시 연결해야 합니다.

## 이전 버전에서 옮기기

이전 버전의 서버를 종료하고 새 폴더에서 실행합니다. 주문을 유지하려면 먼저 앱에서 전체 백업을 내려받고 새 버전에서 복원합니다. 복원은 인증정보를 옮기지 않으므로 계정 인증을 다시 설정합니다. 같은 Windows 계정에서 원래 암호화 세션까지 유지하려면 서버를 종료한 상태에서 기존 `data` 폴더 전체를 새 프로그램 폴더로 복사할 수 있습니다. 원본 폴더와 백업은 보관하세요.

## 확인 범위

설치본 샵마인에서 확인한 고정 HTTPS GET 조회 계약을 독립적으로 구현했습니다. 공개된 ESM 공식 API라는 뜻은 아니며, 서비스 변경 시 수정이 필요할 수 있습니다. 합성 응답·로컬 HTTP·Chrome 화면 검증은 완료했습니다. 실제 확장 설치·실계정 로그인·외부 주문 조회는 미검증입니다. 송장 전송·취소 승인·배송대행 최종 접수는 이 ESM 클라이언트에 포함하지 않습니다. 전체 공급자 범위는 [연동 범위](INTEGRATIONS.md), 도우미의 상세 동작은 [도우미 안내](../browser-helper/README.md)를 확인해주세요.
