# 카페24 관리자 로그인과 주문 수집

새 카페24 연결은 관리자 ID·비밀번호와 쇼핑몰 번호로 로그인합니다. 기존 OAuth 연결은 별도로 보존합니다. 쇼핑몰 번호는 멀티쇼핑몰의 `shop1`, `shop2` 등에 해당하며, 접속 도메인과 구분합니다.

일반 로그인은 카페24 서버가 반환한 `sEncData`·`sEncKey`를 이용합니다. 보안접속, 추가 인증, 자동입력방지, 비밀번호 변경 안내는 로그인 창에서 사용자가 정상 완료합니다. 원본에 있던 추가 인증 생략 필드와 비밀번호 변경 유예 요청은 실행하지 않습니다. 로그인 화면을 닫거나 쿠키 이름이 존재하는 것만으로 연결을 완료하지 않습니다.

로그인 후 실제 응답한 관리자 도메인과 `multishopList`가 반환한 쇼핑몰 번호·표시명을 확인합니다. 최초 연결에서 확인한 `관리자도메인/shop번호`를 고정하며, 다른 상점 세션으로 바뀌면 중단합니다. 이 식별자는 관리자 로그인 ID 자체가 원격 검증되었다는 뜻은 아닙니다. 호스트와 쿠키는 비밀 저장소의 세션 정보로 복원합니다.

## 주문 수집 범위

샵마인에서 확인한 관리자 Excel 생성·다운로드 경로를 사용합니다. 상품준비중, 마켓발주, 배송준비중, 배송대기, 배송중, 배송완료, 취소, 반품, 교환의 9개 목록을 차례로 수집합니다. 취소·반품·교환은 전체 처리 상태를 요청하고, 관련 이력이 있는 품목을 발송 대상에서 제외합니다.

**일반 주문은 원본의 결제일 기준을 유지합니다. 주문일에는 CSV의 발주일을 보존하므로, 늦게 결제한 주문은 조회 기간보다 앞선 주문일로 나타날 수 있습니다.** 취소·반품·교환은 원본의 주문일 필터를 유지합니다.

조회는 관리자 서버에 Excel 생성 작업과 다운로드 이력을 남깁니다. 파일 생성 사이에 11초 간격을 두고, 개별 작업 완료는 최대 25회까지 4초 간격으로 확인합니다. 중복 작업과 혼동하지 않도록 요청 전 목록에 없던 작업이며 상점·목록 분류가 일치한 파일만 읽습니다. 다른 프로그램이 같은 분류의 파일을 동시에 생성하면 하나로 확인할 수 없어 중단할 수 있습니다.

서버가 암호화 ZIP을 요구하면 작업마다 임시 난수 암호를 만들며, AES와 기존 ZipCrypto ZIP을 지원합니다. 원본의 고정 암호는 복제하지 않습니다. ZIP·해제 데이터는 20 MiB, CSV는 10,000품목, 조회 기간은 93일로 제한합니다. 파일을 디스크에 풀지 않으며, CSV 문자열로 주문번호·품목번호·우편번호의 앞자리 0과 긴 숫자를 보존합니다. 통화의 소수 금액 등 현재 정수 금액 모델에서 표현할 수 없는 값은 임의로 반올림하지 않고 중단합니다.

뒤쪽 목록의 오류, 생성 지연, 잘못된 필수 열, 상점 변경, 손상된 ZIP 등이 있으면 앞서 받은 주문까지 포함해 전체 수집을 실패시킵니다. 정상 완료한 전체 결과만 저장 계층에 전달합니다. 화면 자동 클릭으로 주문 확인·발송·취소 승인을 수행하지 않습니다.
