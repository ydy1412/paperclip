# 네이버페이·아임웹·토스쇼핑·고도몰·NH마켓·도매꾹 연결

판매처 연결에서 **판매자 로그인**을 선택하고 로그인 ID를 입력합니다. 정상 로그인창의 추가 인증은 사용자가 완료합니다. 입력한 ID만으로 서버 계정 검증에 성공했다고 표시하지 않습니다. 비밀번호·쿠키·토큰은 일반 연결 응답이나 백업에 포함하지 않습니다.

| 판매처 | 입력·로그인 | 연결 확인과 수집 |
|---|---|---|
| 네이버페이 | 네이버 로그인창을 사용합니다. 가맹점이 여러 개면 스토어명 입력란에 연결할 **가맹점 ID**를 입력합니다. | 가맹점 선택 후 서버 `merchantNumber`를 고정합니다. 판매자센터 CHECKOUT GraphQL의 신규·발주확인·배송·구매확정·취소·반품·교환 21개 조회를 전체 페이지 수집합니다. |
| 아임웹 | 실제 상점 HTTPS 호스트와 관리자 ID를 입력합니다. 일반 로그인 후 필요한 2단계 인증은 로그인창에서 완료합니다. | 상점 도메인에서 정상 세션을 토큰으로 교환하고 OMS API의 12개 상태와 주문별 상세를 읽습니다. 원본에는 교환 전용 조회 계약이 없습니다. |
| 토스쇼핑 | 정상 로그인창에서 인증합니다. 여러 판매자가 연결되어 있으면 스토어명 입력란에 **판매자명**을 정확히 입력합니다. | `my-info`의 서버 회원 번호와 선택한 판매자 번호를 함께 고정합니다. 일반 6상태와 취소·반품·교환의 17개 처리 상태를 수집합니다. |
| 고도몰 | 상점의 실제 **관리자 HTTPS 호스트**와 관리자 ID를 입력합니다. 보안 인증은 정상 로그인창에서 완료합니다. | 관리자 주문 화면의 실제 상태 라벨을 확인하고 상태별 목록·다음 페이지·품목 상세를 읽습니다. 원본 프로그램이 변경하는 원격 엑셀 양식은 수정하지 않습니다. |
| NH마켓 | ID·비밀번호로 로그인 토큰과 휴면 계정 확인 절차를 진행합니다. | 원본의 주문 엑셀 HTML을 EUC-KR로 읽습니다. 신규 계열·배송완료·구매확정·취소·부분반품·부분교환을 포함한 14개 메뉴의 모든 페이지를 수집합니다. 원본의 배송중 조회는 구현이 없는 경로입니다. |
| 도매꾹 | 일반 ID·비밀번호 또는 정상 로그인창의 네이버 로그인을 사용합니다. 비밀번호 변경 안내도 로그인창에서 사용자가 처리합니다. | 상태별 JSON의 17개 조회를 수집합니다. 취소·반품·교환과 철회 내역을 구분하고 원본 주문번호의 `OR` 접두어를 보존합니다. |

아임웹·고도몰·NH마켓·도매꾹의 선택된 원본 경로에는 서버가 로그인 ID를 반환해 대조하는 완전한 계약이 없습니다. 일반 비밀번호 제출 후 인증된 판매자 화면 확인과 브라우저 세션의 사용자 확인을 구분합니다. 설정 ID로 만든 연결 식별자를 서버 계정 번호라고 표현하지 않습니다. 네이버페이·토스쇼핑은 실제 서버의 가맹점·판매자 번호를 대조합니다.

## 기간과 배송 가능 여부

- 스마트스토어와 네이버페이 일반 주문의 조회 기준은 **결제일**입니다. 실제 주문 생성일은 화면 주문일에 보존합니다. 스마트스토어의 자세한 안내는 [SMARTSTORE.md](SMARTSTORE.md)에 있습니다.
- 네이버 계열 클레임은 조회 종료 후 접수된 변경도 반영하기 위해 오늘까지 확인한 뒤 해당 결제일 범위의 주문에 연결합니다. 토스쇼핑 클레임은 원본의 `fromPaidDate`·`toPaidDate` 기준입니다.
- 도매꾹 배송중·배송완료는 원본의 **발송일** 조회를 사용합니다. 그 외 일반 주문은 주문일 기준입니다. 조회된 주문의 원래 주문일이 입력한 기간보다 이전일 수 있습니다.
- 활성·완료 클레임, 부분 수량 또는 알 수 없는 상태는 발송 가능 수량을 추정하지 않습니다. 배송지가 불완전한 경우에도 자동 배송을 막습니다.
- 아임웹에 다중 배송지가 있어 품목과 배송지를 확정할 수 없으면 전체 수집을 중단합니다. 첫 배송지를 모든 품목에 임의로 붙이지 않습니다.
- NH마켓 원본의 신규·발송대기는 같은 102 상태를 조회한 뒤 샵마인 전용 발주확인 기록 API로 구분합니다. 타사 발급정보와 내부 API를 복제하지 않아 독립 앱에서는 102 품목을 중복 없이 수집하고 확인 필요·발송 가능 수량 0으로 표시합니다.
- 도매꾹 원본은 주소를 별도 서비스에 보내 우편번호를 보완합니다. 해당 서비스를 복제하지 않습니다. 조회 응답에 주소만 제공된 품목은 우편번호 미확인·발송 가능 수량 0으로 표시합니다. `ccon`은 개인통관번호이며 클레임 코드로 사용하지 않습니다.

모든 페이지·품목·상태를 검증한 뒤 `complete: true` 결과를 반환합니다. 중복 페이지, 총계 변경, 로그인 화면, 응답 오류 또는 상한 도달은 부분 성공으로 저장하지 않습니다. 수집량은 한 번에 10,000품목 이내로 제한합니다. 원본이 제공하지 않는 기능과 위 제한은 완료 표시와 별도로 안내합니다.
