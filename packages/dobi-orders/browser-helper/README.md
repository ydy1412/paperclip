# 도비 오더스 브라우저 도우미

이 폴더는 Chrome/Edge용 Manifest V3 확장 프로그램 **산출물**입니다. 현재 PC에 설치하거나 실행하지 않았습니다. 접속할 수 있는 Dovix 주문 작업실과 함께 사용합니다.

## 사용 준비

1. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 개발자 모드를 켭니다.
2. **압축해제된 확장 프로그램을 로드**하고 Dovix에서 내려받은 ZIP을 푼 폴더를 선택합니다.
3. 도비 오더스 앱의 연결 화면에서 일회용 코드를 발급합니다.
4. 브라우저 도우미 팝업에 그 코드를 직접 입력합니다. 내려받은 도우미에는 현재 Dovix 서버와 회사·프로젝트 경로가 설정됩니다. 원본 standalone 개발 기본값은 `http://127.0.0.1:4317`입니다.

기본 권한은 `activeTab`, `scripting`, `storage`와 로컬 앱 주소만입니다. 주문 표·배송 초안은 사용자가 도우미를 누른 현재 탭의 표시된 DOM만 확인합니다. 로컬 앱의 연결 토큰은 `chrome.storage.local`에 저장하며 연결 해제로 삭제할 수 있습니다. 쿠키값을 확장 저장소에 저장하지 않습니다. 앱 쪽 토큰 취소가 제공되는 경우 앱에서도 연결을 취소해주세요.

## 지마켓·옥션 세션 연결

1. 원하는 브라우저 프로필에서 ESM에 **직접 로그인**합니다. 비밀번호·OTP·추가 인증은 사이트에서 직접 진행합니다.
2. 도비 오더스 앱에서 지마켓·옥션 연결의 판매자 아이디를 확인하고 **세션 연결 승인**을 발급합니다. 승인은 5분 동안 한 번만 사용할 수 있습니다.
3. 같은 브라우저의 로그인한 ESM 탭에서 도우미를 열고 **ESM 세션 연결**을 선택합니다. 앱에서 승인한 판매자 계정을 고릅니다.
4. **현재 ESM 탭과 승인 확인**을 누르고 표시된 판매자와 사이트를 확인합니다.
5. 로그인 쿠키 사용 동의를 체크하고 **지마켓·옥션 세션 연결**을 누릅니다. 이 클릭에서만 ESM 쿠키용 선택 권한을 요청합니다. 권한을 거절하면 쿠키를 읽거나 전송하지 않습니다.

허용되는 현재 탭 origin은 `https://www.esmplus.com`, `https://seller.esmplus.com`, `https://post-tx.esmplus.com`, `https://signin.esmplus.com`입니다. 준비 후 탭·URL·선택한 계정·승인이 바뀌면 다시 확인해야 합니다.

도우미는 `getAllCookieStores()`의 `tabIds`로 현재 탭을 포함한 저장소 하나를 확인하고 그 저장소에서 `domain: 'esmplus.com'`으로만 쿠키를 가져옵니다. 다른 저장소를 대신 사용하지 않으며 파티션 쿠키는 제외합니다. 이름·값·도메인·경로·hostOnly·secure·만료 정보를 검증하고, 서버와 같은 최대 200개/정규화된 JSON 30,000자로 제한합니다. Cookie 값의 RFC 문법과 지마켓(`gmarket`)/옥션(`auction`) 계정 구분도 검증합니다. 유효한 `ESM_AUTH`가 없으면 재로그인을 안내합니다. [Chrome cookies API](https://developer.chrome.com/docs/extensions/reference/api/cookies)

쿠키는 잠깐 메모리에서만 보관해 설정된 Dovix 경로의 `/bridge/esm-session`으로 한 번 POST합니다. 팝업·로그·확장 저장소에 쿠키값을 출력하거나 저장하지 않습니다. 앱은 승인된 판매자 계정을 SellerList로 대조하고 Dovix의 암호화 비밀 저장소에 저장합니다. 전송 성공/실패 후 선택 권한을 해제하며, 해제가 확인되지 않으면 확장 관리에서 해제하도록 안내합니다. 선택 권한은 `cookies`와 `https://*.esmplus.com/*`이고 버튼의 사용자 동작에서 요청합니다. [Chrome permissions API](https://developer.chrome.com/docs/extensions/reference/api/permissions)

ESM 세션이 만료되거나 로그아웃하면 앱에서 새 승인을 발급하고 다시 연결해주세요. 실제 비밀번호·OTP 입력이나 인증 제한 우회는 수행하지 않습니다.

## 주문 표 수집

쇼핑몰 사이트에서 직접 로그인하고 주문 목록을 연 뒤, 도우미에서 앱에 등록한 **브라우저 방식** 연결을 선택합니다. 현재 사이트의 origin이 그 연결의 `browserUrl`과 정확히 같아야 합니다.

**현재 탭 주문 표 미리보기**를 누르면 주문번호·상품명 등의 명확한 열 이름이 있는 표시된 HTML 표만 읽습니다. 표가 여러 개면 사용할 표를 선택합니다. 원본 주문번호·수량·금액을 확인하고 확인란을 체크한 다음 **미리본 주문을 로컬에 저장**을 누릅니다. 최대 5,000행이며 미리보기는 최대 30개입니다. 다른 페이지를 자동으로 넘기거나 숨겨진 값·인증정보·쿠키·브라우저 저장소를 읽지 않습니다.

화면에 일부 상품만 표시됐거나 표 구조/열 이름이 다르면 수집하지 못할 수 있습니다. 전체 기간 수집이나 API 수집 성공으로 표시하지 않습니다. 날짜/금액/수량이 불명확한 행은 건너뜁니다. 표에 수취인 주소 등이 없다면 앱에서 보완하거나 쇼핑몰의 파일을 가져와주세요.

## 배송 신청 초안

앱에서 배송대행지용 초안을 만든 뒤 해당 사이트에서 직접 로그인하고 신청서를 엽니다. **현재 탭 입력 대상 미리보기**를 누르면 초안 값과 현재 입력값을 비교할 수 있습니다. REA 정적 매핑 후보 중 변환·분할·같은 필드의 여러 selector·인증·약관·라디오·제출 요소는 제외합니다. 입력 대상 수가 상품 수와 다르거나 원본 값이 비어 있으면 건너뜁니다.

확인란을 체크하고 **확인한 초안 값 채우기**를 누른 경우에만 `input`/`textarea`의 값과 일반 input/change 이벤트를 적용합니다. 미리보기 후 사용자가 입력한 값을 바꿨거나 탭이 바뀌면 다시 확인해야 합니다. 약관·라디오·제출 버튼을 조작하지 않으며 신청 성공으로 기록하지 않습니다. 사이트에서 내용을 검토하고 직접 제출해주세요.

## 확인 범위

정적 후보는 샵마인의 해당 빌드에서 발견한 입력 selector를 근거로 합니다. 현재 사이트 DOM과 실제 서비스 연동은 검증되지 않았습니다. 신청서가 iframe·캔버스·사용자 지정 요소 안에 있거나 사이트가 변경되면 입력 대상을 찾지 못할 수 있습니다. 로그인/추가 인증/최종 신청/송장 회수는 자동화하지 않습니다.

아래 경로는 원본의 상대 계약이며, Dovix에서는 `/api/companies/:companyId/sourcing/projects/:projectId/order-management` 아래로 연결됩니다. 서버 계약: `/api/bridge/pair`, `/api/bridge/context`, `/api/bridge/draft/{id}`, `/api/bridge/browser-orders`, `/api/bridge/esm-session`. 연결 요청 후에는 `X-Dobi-Bridge` 헤더로 인증합니다. ESM 세션 동의 전에는 기본 권한만 사용하며 쿠키 API를 호출하지 않습니다.

검증: 기존 합성 DOM/VM 테스트 7개와 ESM 세션 Chrome API mock 테스트 14개가 통과했습니다. 기본 표·배송 초안의 암호/OTP/숨김/제출 요소 제외와 원값/도메인/탭 검증을 유지했습니다. 세션 테스트는 권한 거절, 잘못되거나 모호한 저장소, ESM 이외 도메인, 계정/승인/탭 변경, 만료·파티션 쿠키, 형식/크기 제한, 로컬 POST 한 번과 화면/로그/저장소 누출 방지를 확인했습니다. 33개·정규화 JSON 36,581자 입력을 서버와 동일하게 전송 전에 거부하는 회귀 테스트도 포함합니다. 실제 확장 설치·실쿠키 조회·Chrome/Edge 권한 창·실사이트 로그인/주문/신청 검증은 수행하지 않았습니다.
